# EMBERFALL

**The world went cold. You didn't.**

A neon survival roguelite. Zero installs, zero dependencies.

## Play

Open `index.html` in any browser, or enable GitHub Pages on this repo
and play at the published URL.

## Controls

- WASD / arrow keys: move
- SPACE: dash
- 1 / 2 / 3: pick upgrades
- ESC: pause
- Touch: left side = joystick, DASH button = dash
- Your weapon fires automatically

Beat Sector 2 to clear the free edition (First Spark).
